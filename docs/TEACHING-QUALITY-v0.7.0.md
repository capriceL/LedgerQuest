# LedgerQuest v0.7.0 教学体验审计

> 日期：2026-11-25  
> 目标：解决反馈 4 中“重点偏向展示知识，用户仍不知道怎么做题”和“抓关键词变成另外一道猜题”的问题。  
> 原则：先理解知识点，再用母题学会下手，最后换条件做变式；不能为了做题而牺牲知识理解。

## 1. 反馈 4 的归因

反馈 4 不是单点文案问题，而是旧概念微闯关把“理解”和“做题”拆成了两套互不相连的动作：

1. 用户先读一段知识。
2. 随后被问“这段在讲哪个考点”。
3. 选项是同一章的其他知识卡名称。

这会让用户产生三个断点：

- 看懂了知识，却不知道拿到考试题干后先做什么。
- 选项只要求认卡名，没有训练条件、数字和规则之间的连接。
- 题目与刚才读到的正文看起来没有关系，容易产生“这题到底在问什么”的陌生感。

## 2. v0.7.0 学习闭环

每张知识卡统一走以下路径：

```text
知识讲解（不计分）
  → 柚柚示范拆母题
  → 用户独立做母题
  → “为什么成立 + 怎么下手”双解析
  → 换条件做变式
  → 通关复盘
```

### 2.1 知识讲解

作答前先显示：

- 人话解释。
- 关键词。
- 题目要你做什么。
- 拿什么数据、按什么口径。
- 柚柚的示范步骤。
- 本题相关分录或判断口径。
- 数字例子。
- 最容易漏的条件。

知识讲解阶段不显示答案选项，避免用户跳过讲解直接猜。

### 2.2 母题

- 优先使用课程练习、课程例题和剧情题中的真实题目。
- 没有可用原题的知识卡，生成只围绕本卡规则、边界和计算口径的母题。
- 题干明确展示条件或资料。
- 支持单选、多选、判断。
- 多选必须选齐；少选、多选都不算通过。
- 答错只提示本题方向，不直接替用户改答案，支持无限重试。

母题题源：

| 来源 | 数量 |
| --- | ---: |
| 课程练习 | 387 |
| 课程例题 | 19 |
| 剧情题 | 93 |
| 知识点派生 | 550 |
| 合计 | 1,049 |

### 2.3 双解析

答对后同时给出：

- **为什么成立**：回到知识点、适用条件和规则本身。
- **怎么下手**：以后遇到同类题，先看什么、取什么数、按什么顺序判断。
- **完整解析**：保留课程题目已有的完整推导，默认折叠，避免首屏过载。

### 2.4 变式

- 1,049 张卡均生成一道本卡变式。
- 变式只从同一张卡的条件和规则迁移，不借用同章其他卡冒充变式。
- 母题与变式不能只是同一组选项换顺序。
- 变式答对后才写入知识卡通关记录。

### 2.5 通关复盘

通关页再次收口：

- 知识本身的人话解释。
- 关键词。
- 题干怎么问、拿什么算。
- 本卡分录或判断口径。
- 母题和变式分别要带走什么。
- 最后的易错边界。

## 3. 内容规模

- 知识卡：1,049 张。
- 母题：1,049 道。
- 变式：1,049 道。
- 合计：2,098 道。
- 单选：1,879 道。
- 多选：127 道。
- 判断：92 道。
- 知识点派生母题和全部变式均通过以下结构检查：
  - 题干不为空。
  - 选项不为空且不重复。
  - 答案索引有效。
  - 多选至少两个答案。
  - 判断题固定两个选项。
  - “为什么成立”“怎么下手”“完整解析”齐全。
  - 母题与变式题干、选项集合不能完全重复。

## 4. 全库边界检查

`challengeHowSteps()` 不再只依赖单句 `howTo`。当一张卡没有足够拆解句时，会按以下顺序补全并去重：

1. 题干识别。
2. 数据/规则口径。
3. 易错边界。
4. 关键词兜底。

浏览器逐卡审计结果：

- 1,049/1,049 张卡的示范步骤不少于两步。
- 不存在空步骤。
- 知识讲解页不提前显示选项。

## 5. 交互回归

真实 Edge 已覆盖：

- 知识页先于选项出现。
- 进入母题后显示关键词和本题要做什么。
- 单选答错、提示、重试、纠错、双解析、变式、通关复盘。
- 多选可选择、可撤选。
- 多选少选会提示漏选数量。
- 多选选齐后显示“为什么成立”和“怎么下手”。
- 判断题两个选项可正常判题并显示双解析。
- 390px 手机和 1440px 桌面均无横向溢出。
- 手机操作栏位于可达区域。

## 6. 质量边界

- 课程原题与例题保留原始条件，不对题干事实做二次改写。
- 自动生成题只做本卡知识检索和边界辨析，不冒充正式机考题、押题或官方题库。
- 课程资料、自动审计和浏览器回归通过，不等同于出版社教材逐字审定或外部专业教师签字。
- 后续新增知识卡必须同时提供母题、变式、双解析和通关记录，否则不得进入正式内容包。
