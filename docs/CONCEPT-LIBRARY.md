# 概念速查库与中文优先术语显示

## 1. 定位

概念速查库不是额外的可玩关卡，而是独立于剧情闯关的“学习索引层”：

- 剧情关卡回答“这一类题怎么一步步做”。
- 概念卡回答“这个知识点是什么、怎么找关键词、拿什么数字算、最容易错在哪”。
- 术语显示层回答“FVTPL、WACC、EOQ 这类英文在中文里叫什么”，但不再单独占用一个知识库栏目。

概念卡与术语映射共用同一份单文件。术语数据只作为显示词典和检索别名使用，避免把数百张概念卡硬塞进首页或每个章节。

## 3. 概念卡结构

```json
{
  "id": "pc-p02-01",
  "subjectId": "practice",
  "subjectName": "中级会计实务",
  "chapterId": "p02",
  "chapterTitle": "存货",
  "title": "存货的确认条件",
  "en": "Inventory Recognition",
  "aliases": ["存货确认", "存货确认条件"],
  "kind": "确认条件",
  "keywords": ["持有目的", "经济利益很可能流入"],
  "plain": "大白话解释，2-4 句。",
  "howTo": "看到题目先抓什么、按什么顺序判断。",
  "formula": "计算式或判断口径。",
  "example": "带数字、期限或场景的短例子。",
  "trap": "最容易混淆的点。",
  "related": ["同包内另一个 id"],
  "verifyStatus": "draft"
}
```

要求：

1. `id` 全局唯一，`related` 不得断链。
2. `title`、`aliases`、`keywords` 要包含可搜索的考试叫法。
3. `plain` 不能只写“很重要，需要掌握”；要说人话。
4. `howTo` 必须能让用户知道“题目想干什么、先找什么、拿什么判断”。
5. 经济法期限、比例和程序通过产品内容审计交叉核验；正式用途仍以最新官方法规文本为准。
6. 概念卡与大纲条目是映射关系；通过门禁不等于教材逐句或外部教师签字已核定。

## 3.1 统一教学层

概念卡之上再叠加 `CONCEPT_TEACHING`，界面按固定顺序输出：

1. 人话：12–160 字，先让用户知道“这东西到底在说什么”。
2. 关键词：题干信号词。
3. 题干怎么问：看到哪些词、先判断什么。
4. 拿什么数字：公式、比较线或判断顺序。
5. 分录/会计处理：借贷方向、科目、金额口径、逐行原因。
6. 顺手记一个例子：短场景或带数字的例子。
7. 最容易翻车：只讲一个坑。

人工讲义优先覆盖复杂/易错点；其余卡片也必须经过同一套字段清洗，不允许把长句、重复卡名标签或旧模板直接丢给用户。

## 4. 术语显示策略

```json
{
  "id": "fair-value",
  "term": "Fair Value",
  "full": "Fair Value (FV)",
  "zh": "公允价值",
  "aliases": ["公允价值", "FV"],
  "subjects": ["practice", "finance"],
  "plain": "市场参与者在计量日有序交易中愿意成交的价格。",
  "example": "同一市场、同一时点，按可观察市场证据确定。"
}
```

同名缩写可能跨科目有不同含义（例如 FV 可指公允价值或终值），因此：

- `glossary-v1.json` 保留 125 条完整映射和科目标签，作为离线显示词典。
- 玩家界面不再提供独立“英文术语”栏目，也不要求用户先学英文。
- 正文统一“中文（英文）”，例如“合同现金流仅含本息（SPPI）”“以公允价值计量且其变动计入当期损益（FVTPL）”。
- 公式保留 `PV`、`FV`、`EBIT` 等变量字母时，公式下方显示“公式字母对照”；判断类公式中的缩写仍直接给中文。
- `FV` 等歧义缩写按上下文判断：财务计算显示“终值”，公允价值场景显示“公允价值”。
- 英文术语只作为补充线索，不遮挡、不替代中文解释。

## 5. 构建流程

当前主文件已是 v0.6.1 封存产物。除非明确执行完整版本升级，否则不得为“检查”而重跑内容生成或嵌入脚本；日常验收只跑审计与测试。内容源确实更新后，才按下例执行完整重建：

## 6. 界面行为

- 概念速查：关键词搜索 + 科目 + 章节 + 类型筛选；每批加载 60 张。
- 概念详卡：先人话，再关键词、题干怎么问、拿什么数字、分录/会计处理、例子、易错点；概念原话折叠在底部。
- 章节知识地图：明确显示“本章全部 N 个考点”，附类型分布和章级分录总览，不做重点抽样。
- 知识库栏目：仅“概念速查”与“闯关知识卡”，不单列英文术语。
- 正文术语：统一中文优先、英文括号补注；只渲染转义后的文本，不执行导入内容中的 HTML。
- 扩展入口：内容工坊可导入剧情内容、导出概念卡；术语映射仍由构建源维护。
