# 产品数据

本目录只保存产品运行、内容构建和质量审计需要的 JSON 数据。

核心文件：

- `concepts-*-v1.json`：三科概念卡与考点注记。
- `content-*-v1.json`：剧情章节、关卡与题目的源数据。
- `concept-teaching-v1.json`：卡片级教学、分录与章节入口。
- `exam-mothers-v1.json`：1,049 张知识卡的母题、双解析与同卡变式数据。
- `glossary-v1.json`：术语显示词典。
- `syllabus-audit.json`：官方大纲映射与覆盖索引。

不包含外部资料、用户材料、浏览器缓存、备份或临时快照。

修改产品内容后，应重新运行根目录 `README.md` 中列出的核心校验命令。
